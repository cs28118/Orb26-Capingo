## How unlocks are wired (product → flag → badge)

| Action | Server flag / counter | Badge |
|--------|----------------------|-------|
| First AI chat (quest) | `helloCapy` | Hello Capy! |
| Add task / manual block | `masterScheduler` | Master Scheduler |
| Generate timetable | `autoAllocating` | Auto Allocating... |
| Drag task to grid | `draggedTask` | Drag it! |
| Overlapping blocks | `multitask` | Multitasker |
| Create deck (quest) | `deckBuilder` + `decksCreated` | Deck Builder / Data miner |
| Edit profile save | `instantiatedIndentity` | Instantiated Identity |
| Accept partner | `connectedComponent` | Connected component |
| Streak / XP level-up | `streakDays` / `level` | Streak & level badges |
| Quest XP awards | `questsCompleted` / daily → streak | Killer Quest I / II |

Client helper: `unlockFromProfile(uid, profile)` → evaluate conditions, toast, `POST /unlock-achievements`.
