## Edge cases

| Case | Expected behaviour | How verified |
|------|--------------------|--------------|
| Legacy cards missing SRS fields | Treated as new/due via defaults | Unit |
| >20 brand-new cards in one session | Queue length capped (default 20) | Unit |
| Again rating | Card requeued soon; lapses increment | Unit |
| Zero cards due | “You’re caught up” empty state; offer cram | E2E `edge-caught-up.png` |
| Cram all | Studies entire deck ignoring due dates | UI present; full cram journey optional manual |
