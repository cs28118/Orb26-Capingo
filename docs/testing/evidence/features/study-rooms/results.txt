## Integration tests

Broad HTTP coverage in `rooms.test.js` / `rooms-admin.test.js`:

| Case | What it proves |
|------|----------------|
| Create group + join by code | Membership + room code works |
| Join when already member | `alreadyMember: true` |
| Unknown join code | **404** |
| DM requires accepted partnership | Non-partner → **403** |
| DM find-or-create | Opening DM twice returns same `roomId` |
| DM with self | **400** |
| Invite partner / non-partner | Partner OK; non-partner **403** |
| Last admin leaves | Remaining member promoted |
| Promote / kick | Admin can manage; non-admin kick **403** |
| Announcements | Admin-only post rules |
| Resources | http(s) URLs; members can add |

Socket.IO live chat is **not** fully covered by HTTP integration; membership checks exist in socket handlers.
