## Unit tests

Backend Vitest in `backend/tests/unit/helpers.test.js` (subject sync helpers):

| Test | What it proves |
|------|----------------|
| `normalizeSubject` | Collapses extra whitespace (`"  Data   Structures  "` → `"Data Structures"`) |
| `extractSubjectsFromTimetable` | Unique subjects from todos/events; empty string ignored; **case-insensitive** dedupe (`Math` / `math`) |
| `intersectSubjects` | Shared subjects matched case-insensitively |
| `jaccardScore` | Overlap score for partner matching (`shared/union`) |

These feed both Timetable subject tags and Study Partners suggestions.
